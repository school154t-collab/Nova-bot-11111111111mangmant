# 🎫 Nova Town — بوت الإدارة + لوحة التحكم (ملف واحد)

كل المشروع في ملف واحد: `novatown.py` — البوت والموقع مع بعض.

---

## 🚀 التشغيل السريع

```bash
pip install -r requirements.txt
python novatown.py
```

يشغّل البوت والموقع في نفس الوقت. الموقع يطلع على المنفذ 5000.

---

## ⚙️ قبل التشغيل — عدّل أعلى ملف `novatown.py`

في قسم **الإعدادات** بالأعلى، أهم شيئين:

| المتغير | الوصف |
|---|---|
| `BOT_TOKEN` | توكن البوت من [Developer Portal](https://discord.com/developers/applications) |
| `GUILD_ID` | ID السيرفر |

> باقي الرومات والرتب (الويتينق، الدن، الإجازات، الترقيات، إداري الأسبوع، رتبة الإدارة، رتبة الإجازة) **مدخلة مسبقاً**.

### سلم الرتب `ROLE_LADDER`
رتّبت السلم من صورك (من Support للأسفل صعوداً لـ Super Admin). كل رتبة فيها اسمها + مكان لـ `id`.
**ضع الـ Role ID لكل رتبة** مكان الـ `0` عشان نظام الترقيات يشتغل بالمنشن. بدونها يعرض الأسماء نصيّاً.

## 🌐 الموقع (الإدارة العليا)

- الرابط: `http://localhost:5000` (أو رابط الاستضافة).
- الباسورد: `NovaTown123RowexM112`
- فيه: النقاط الأسبوعية والإجمالية، الإجازات (تعديل المدة / إعادة الحساب)، وموعد إداري الأسبوع.

## 📊 الأنظمة

**التكتات:** لوحة بالأقسام (استفسار، شكوى على إداري، باند، حماية، تعويض، استراتيجي، متجر) + منع سبام + زر استلام (+5 نقاط) + تقييم بالخاص من 5.

**الويتينق:** دخول شخص → إشعار للإداريين + زر استلام يسحبه لروم الإداري (+3 نقاط) + زر "تم الانتهاء" ينقله لروم Done.

**النقاط:** أسبوعية (تُصفّر بعد إعلان إداري الأسبوع) + إجمالية (تبقى).

**إداري الأسبوع:** الأكثر نقاطاً، كل خميس 8 مساءً بتوقيت السعودية (قابل للتغيير من الموقع).

**الإجازات:** يقرأ النموذج، يعطي رتبة الإجازة، يحسب المدة، يفحص كل 20 ساعة ويشيل المنتهية.

**الترقيات:** يقرأ النموذج وينشره منظّم (By ثابتة: Nova High Mangment).

## 🆕 تحديثات هذه النسخة

- **سلم الرتب كامل** بالـ IDs (15 رتبة من Support لـ Super Admin).
- **الترقية بالعدد:** أضف سطر `Count : 2` في نموذج الترقية → يترقّى درجتين مرة وحدة. بدون السطر = درجة وحدة.
- **رتبة إداري الأسبوع** تُعطى تلقائياً للفائز وتُشال منه عند اختيار التالي.
- **وقت إداري الأسبوع** الافتراضي: الخميس 8:05 مساءً (قابل للتغيير من الموقع).
- **جماليات محسّنة** لكل رسائل البوت: ألوان مميزة لكل نظام، فواصل أنيقة، بنرات، وأيقونات.
- أمر جديد `!ladder` يعرض سلم الرتب.

### نموذج الترقية المحدّث
```
Name : <@USER_ID>
From : <@&الرتبة_الحالية>
To: <@&الرتبة_الجديدة>
Reason : السبب
Count : 2
```
> `Count` اختياري. لو تركته، الترقية درجة وحدة.

في أعلى الملف، حط رابط شعار NT في `BRAND_ICON` ورابط بنر عريض في `BRAND_BANNER` — بيظهران في كل الرسائل المهمة.

## 🖼️ إضافة شعار NT (مهم للجماليات)

البوت والموقع يدعمان شعارك. عشان يظهر:

1. ارفع صورة شعار NT في أي روم بديسكورد، أو في Server Settings → Emoji.
2. انسخ رابط الصورة المباشر (Copy Link / Copy Image Address).
3. في أعلى `novatown.py` حط الرابط في:
   - `BRAND_ICON` — يظهر في كل رسائل البوت + الموقع (تسجيل الدخول والهيدر).
   - `TICKET_LOGO` — شعار خاص بالتكتات (لو تركته فاضي يستخدم `BRAND_ICON`).
   - `BRAND_BANNER` — بنر عريض اختياري يظهر أسفل الرسائل المهمة.

> بدون الروابط كل شي يشتغل عادي، بس بشعار NT الافتراضي (نص "NT").

## 🔐 صلاحيات أقسام التكتات (محدّثة)

كل قسم يفتحه العضو يشوفه فقط الرتب المختصة (غير صاحب التكت):

| القسم | من يشوف ويستلم |
|---|---|
| استفسار | كل الإدارة |
| شكوى على إداري | الرتبة المختصة فقط |
| باند | رتبة الباند فقط |
| تعويض | رتبة التعويض فقط |
| استراتيجي | الرتبة المختصة فقط |
| متجر | رتبة المتجر فقط |

> قسم **الحماية حُذف**. التكتات تنفتح تحت الكاتقوري المحدد، والصلاحيات تُضبط تلقائياً لكل قسم.
> لتعديل رتب أي قسم: عدّل `roles` في `TICKET_CATEGORIES` بأعلى الملف (قائمة فاضية = كل الإدارة).

أضيف تبويب **"التقييمات"** في لوحة الإدارة العليا يعرض:

التقييمات تُجمع تلقائياً من تقييمات التكتات اللي يعطيها الأعضاء بالخاص بعد إغلاق التكت.

## 👋 نظام الترحيب (Welcome)

أول ما عضو جديد يدخل السيرفر، البوت يرسل رسالة ترحيب أسطورية في روم الويلكوم فيها:
- اسم العضو + صورته + منشن.
- عدد الأعضاء الكلي، الايدي، عمر الحساب (مع توثيق للحسابات أقدم من 7 أيام).
- تاريخ الانضمام واسم السيرفر.

**للتجربة:** اكتب `!testwelcome` (للأدمن) ويعرض الرسالة عليك.

**البنر:** حط رابط بنر عريض في `WELCOME_BANNER` بأعلى الملف ليظهر أسفل رسالة الترحيب.

> ملاحظة: خانتي "مين دعاه" و"الكود" في النموذج المرجعي تحتاج نظام تتبّع دعوات (invite tracking) منفصل ومعقّد؛ النظام الحالي يعرض باقي البيانات كاملة. لو تبي تتبّع الدعوات لاحقاً نضيفه.

## 🎛️ لوحة تحكم المالك (تشغيل / إطفاء)

البوت يبدأ **مطفأ افتراضياً** (متصل لكن صامت). للتحكم:

1. أرسل **أي رسالة خاصة (DM)** للبوت — بس المالك (ID في `OWNER_ID`) يقدر.
2. تطلع لك لوحة فيها زرين:
   - 🟢 **تشغيل** — يفعّل كل الأنظمة (تكتات، ويتينق، ترحيب، إجازات، ترقيات) وينشر لوحة التكتات تلقائياً.
   - 🔴 **إطفاء** — يوقف كل الأنظمة (البوت يظل أونلاين لكن صامت).
3. الحالة محفوظة — حتى لو أعيد تشغيل الاستضافة، البوت يتذكر آخر حالة.

> وقت الإطفاء: ما يفتح تكتات، ما يرحّب، ما يرد على النماذج. حالة البوت في ديسكورد تتغير (Watching).

## 🎫 ميزات التكتات المتقدمة (جديد)

**الأسئلة الشائعة (FAQ):** زر في لوحة التكتات يعرض:
- هل النقل فاتح؟ → نعم، تواصل مع الإدارة العليا.
- كيف أدخل السيرفر؟ → اكتب الاسم في فايف إم أو توجّه للروم المحدد.

**أزرار داخل كل تكت:**
- ✋ استلام · 🔔 استدعاء العضو · 👥 إضافة عضو · 📌 الأولوية (عادي/مهم/عاجل) · 🔐 قفل · 🔒 إغلاق

**النسخة الاحتياطية (Transcript):** عند إغلاق أي تكت، تُحفظ المحادثة كاملة وتظهر **بالموقع** (تبويب التكتات → زر "عرض"). صفحة أنيقة فيها كل الرسائل والصور.

**التقييم:** بعد الإغلاق، تقييم 5 نجوم يُرسل للعضو **بالخاص (DM)** ويظهر في تبويبي "التقييمات" و"التكتات" بالموقع.

**تنبيه التكت المتأخر:** لو مر أكثر من 30 دقيقة على تكت بدون استلام، البوت ينبّه الإدارة (قابل للتغيير في `TICKET_LATE_MINUTES`).

**إحصائيات بالموقع:** تبويب "التكتات" يعرض: الإجمالي، المفتوح، المغلق، متوسط التقييم، والتوزيع حسب القسم.

## 📋 سجل الإجازات بالموقع (جديد)

تبويب "الإجازات" في الموقع صار فيه قسمين:
- **الإجازات النشطة:** بطاقات مع الوقت المتبقي وأزرار التعديل.
- **سجل الإجازات (الكل):** جدول بكل الإجازات (نشطة ومنتهية) مع العضو، المدة، السبب، وقت البداية والنهاية، والحالة.

البوت يفحص كل 20 ساعة: الإجازات المنتهية تُشال رتبتها تلقائياً وتتحول لـ"منتهية" في السجل، والنشطة تبقى. كل شي مسجّل ويظهر بالموقع.

## 🤍 رسالة الويتينق الخاصة + روم الأذكار (جديد)

**رسالة الويتينق (DM):** أول ما عضو يدخل روم الويتينق، يوصله بالخاص رسالة محترمة تذكّره يملأ وقت الانتظار بالاستغفار، مع حديث في فضل الاستغفار.

**روم الأذكار:** كل **3 ساعات** يرسل البوت في روم الأذكار (`ATHKAR_CHANNEL_ID`) ذكراً/دعاءً/آية/تسبيحاً بشكل جميل مع المصدر والنوع.

- **المحتوى:** ~72 عبارة مختارة ومدقّقة (أذكار، أدعية نبوية وقرآنية، آيات قصيرة، تسابيح) من مصادر معروفة (البخاري، مسلم، أبو داود، الترمذي...).
- **الإضافة:** تقدر تضيف المزيد بسهولة — في أعلى الملف قائمة `ATHKAR`، أضف سطراً:
  ```python
  {"type": "دعاء", "text": "نص الدعاء", "source": "المصدر"},
  ```
  كل ما تضيف أكثر، التنويع أكبر (تقدر توصلها لآلاف بعبارات تثق فيها).

**أوامر التجربة (للأدمن):**
- `!thikr` — يرسل ذكراً الآن في روم الأذكار.
- `!testwelcome` — يجرّب رسالة الترحيب.

## 🔧 تحسينات الإصدار الأخير

1. **المدة أُصلحت:** الآن يفهم "يومين"=48 ساعة، "ساعتين"=2، "اسبوعين"=336، والأرقام المكتوبة بالحروف.
2. **حذف الإجازة:** لو حُذفت رسالة الإجازة، البوت يلغيها ويشيل الرتبة تلقائياً (لا تُحتسب).
3. **زر الترقية بالموقع:** جنب كل إداري زر "⬆️ ترقية" — يفتح نافذة (عدد الدرجات + السبب)، والبوت ينفّذها خلال ثوانٍ وينشر إعلانها.
4. **أسماء التكتات محسّنة:** `📩・استفسار・اسم-العضو` بدل الاسم القديم.
5. **الأولوية تظهر بصرياً:** تحديد "عاجل" يضيف 🔴 لاسم الروم، و"مهم" يضيف 🟡.
6. **قفل/فتح:** زر واحد يبدّل بين القفل والفتح.
7. **صاحب التكت يقدر يغلق تكته** بنفسه (بدون انتظار المختص).
8. **تصميم الموقع محسّن:** حواف أنعم، شعار NT كعلامة مائية في بطاقة إداري الأسبوع، ألوان وتباعد أرقى.
9. **نقاط التكت = 3، السحب = 3.**

## 🔄 فحص الإجازات كل ساعتين + لوق العمليات (جديد)

- البوت يفحص الإجازات المنتهية **كل ساعتين** (كان 20 ساعة) — يشوف من انتهت مدته ويشيل رتبة الإجازة تلقائياً.
- **لوق العمليات بالموقع:** في تبويب "الإجازات" أُضيف جدول "🧾 سجل عمليات الإجازات" يسجّل كل عملية:
  - 🟢 بدأت الإجازة · 🟡 انتهت الإجازة (أُزيلت الرتبة) · 🔴 أُلغيت الإجازة (حُذفت الرسالة)
- يعرض أيضاً **آخر وقت فحص** ومعدل الفحص.
